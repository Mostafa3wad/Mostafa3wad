<br/>

```dart
// Every project I build follows strict layer separation
//
//   ┌─────────────────────────────────────────┐
//   │  PRESENTATION   →  UI · Cubit · Widgets  │
//   ├─────────────────────────────────────────┤
//   │  DOMAIN         →  Entities · UseCases   │  ← Pure Dart. Framework-free.
//   ├─────────────────────────────────────────┤
//   │  DATA           →  API · Models · Repo   │
//   └─────────────────────────────────────────┘
//
// → UI never touches business logic
// → Domain knows nothing about Flutter
// → Data layer handles only I/O
// → Errors propagate cleanly: data → domain → presentation
```
